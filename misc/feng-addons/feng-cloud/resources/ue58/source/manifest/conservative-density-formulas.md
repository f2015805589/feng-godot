## Branch defaults and channel formulas

The default instance does not override `StormClouds`, `UseNoise3`, or the listed scalar/vector inputs. `StormClouds` has no serialized scalar default and resolves to CDO zero; `UseNoise3` resolves to CDO false. The parent graph’s active custom output connects `MakeFloat4` call 10 to `ConservativeDensity`; its X/Y/Z/A FunctionInput GUID map is in the closure JSON. UE’s `FExpressionInput` is 36 bytes (`MaterialExpression.h:44-79`); all 28/28 serialized function inputs resolved to expression exports/imports.

- `ConservativeDensity.r = ConservativeDensity.g = max(Pattern.r, Pattern.g, Pattern.b)`. Both channels reach `Max_3 -> Max_4`; the default `StormClouds=0` selects each Lerp A input. The `_25.R`, `_20.G`, `_26.B` samples are multiplied by `Layout_CloudType.rgb=(1,1,1)` and use `Layout_CloudGlobalPattern`, overridden to `T_CloudPattern`. Their defaults are `TMVM_None` (implicit derivative mip selection), `SSM_Wrap_WorldGroupSettings`, and `SAMPLERTYPE_LinearColor`.
- `ConservativeDensity.b = max(Profile.r(alt, Pattern.r), Profile.g(alt, Pattern.g), Profile.b(alt, Pattern.b)) - 0.5`. The profile samples are `_19.R`, `_18.G`, `_17.B` from instance override `T_Profile_08`, each at `TMVM_MipLevel=0`. UV is `(NormAltitudeInLayer, corresponding Pattern channel)`; `CloudSampleAttribute_3` output 2 supplies normalized altitude (0 at layer bottom, 1 at top; `MaterialExpressions.cpp:21648-21670`). `Layout_CloudType.rgb=(1,1,1)`.
- `ConservativeDensity.a = Noise_Strength.r(0.8) * (Noise3(sample9.G, coord9, LOD0) - Noise_Bias.r(0.5) + Cloud_GlobalCoverage(-0.2))`. `UseNoise3=false` selects this serialized B branch; it still samples the 3D noise texture. `sample9` and `sample12` use instance override `VT_PerlinWorley_Balanced` (`Noise_Texture3D`) with explicit `TMVM_MipLevel=0`; `sample12.R` contributes to the `sample9` coordinate perturbation. The coordinate is `coord9 = Add17 + (q, q, (2*abs(q-0.5))^2) * (0.08 * (sample12.R(coord12, LOD0)-0.8))`, where `q=0.05+0.95*NormAltitudeInLayer`; this is the TextureSample UV input. The constants are closure-edge-backed: Multiply_18.B <- Reroute_5 <- Noise_Strength output 1 with R mask (CDO R=0.8); Subtract_3.B <- Reroute_2 <- Noise_Bias output 1 with R mask (CDO R=0.5); Subtract_3.A is TextureSample_9 G. The separate q-coordinate modulation uses Noise_Strength output 2 with G mask (0.08) and Noise_Bias output 2 with G mask (0.8). Full coordinate ancestry is retained as nodes/edges in the closure JSON. Relevant parent defaults: `Noise_Strength=(0.8,0.08,0.03,2.5)`, `Noise_Bias=(0.5,0.8,0.5,0)`, `Cloud_GlobalCoverage=-0.2`, `Noise1_Coordinates=(4.167,4.444,9.091,7)`, `Noise2_Coordinates=(60,60,75,-6)`, `Layout_WindControls=(1,1,0.5,0.333333)`, `Layout_CloudGlobalScale=256 km`. The active sample coordinates depend on WorldPosition, wind, Time, and `Layout_GlobalTexturePlacement`; for the serialized default material/instance, the latter has no serialized vector default or default-instance override and its VectorParameter CDO default is zero `(0,0,0,0)`. A runtime MID may explicitly override it.

Mip provenance: the profile samples serialize mip 0 directly. The 3D sample mip pins connect to Constant nodes with no serialized R; `UMaterialExpressionConstant` has no constructor assignment to R (`MaterialExpressions.cpp:5057-5065`), so the CDO-zero input is 0. Pattern samples omit MipValueMode and use the TextureSample CDO constructor default `TMVM_None` (`MaterialExpressions.cpp:2586`).

## Active Deferred SubsurfaceColor

`SubsurfaceColor = saturate( If(NormAltitudeInLayer, 0.5, greater=0, equal=1, less=0, threshold=0.48) * 0.008 * saturate(length(WorldPosition_2_cm)*1.9999999495e-5) * (0.001*dot(T_CloudMask_sample*Layout_CloudType.rgb, Layout_CloudTypeMask.rgb) + CD.g*(CD.b+CD.a)) )`. `WorldPosition_2` explicitly serializes `WorldPositionShaderOffset=WPT_CameraRelative`; UE maps this to `GetTranslatedWorldPosition(Parameters)` / `MCT_Float3`, including material shader offsets (`MaterialExpressionWorldPosition.h:13-26`, `MaterialExpressions.cpp:12249-12266`, `HLSLMaterialTranslator.cpp:6218-6260,6280-6292). The length is in translated camera-relative centimeters.

Here `CD` is the runtime `VolumeSampleConservativeDensity` float4 read by `MaterialExpressionVolumetricAdvancedMaterialInput_3` output 1; the material’s custom output supplies the float4 built above. The If uses UE’s generated semantics `abs(A-B)>threshold ? (A>=B ? greater : less) : equal` (`MaterialExpressions.cpp:11091-11122`, `HLSLMaterialTranslator.cpp:6573-6610`). Thus the If factor is 1 for normalized altitude within 0.48 of 0.5 (approximately `[0.02,0.98]`) and 0 outside. The camera-distance term is in cm because `WorldPosition_2` is `WPT_CameraRelative`.

The mask branch is graph-connected through `Layout_GlobalCloudMask` (default instance texture `T_CloudMask`), but the parent’s `Layout_CloudTypeMask` default is `(0,0,0,1)` and the instance has no vector overrides; the dot product uses RGB only, so this term is zero for the default instance. The remaining default subsurface term is `saturate(IfFactor * 0.008 * distanceFade * CD.g*(CD.b+CD.a))`.

## Limits

This is serialized active-graph expansion plus source/CDO branch resolution, not UE material shader compilation or numerical texture evaluation. Texture values and unresolved runtime vectors are symbolic. The closure is specifically the actual default Deferred path; it does not claim Forward/Mobile equivalence. Profile/Pattern/Mask shared-sampler runtime details follow `SSM_Wrap_WorldGroupSettings`; asset filter metadata alone is not treated as proof of the effective sampler.
