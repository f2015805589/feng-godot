# Atmosphere reference attribution

The independently written Feng transport follows the published spherical-medium
and multiple-scattering approach illustrated by Sébastien Hillaire's
`sebh/UnrealEngineSkyAtmosphere` sample. Reference revision:
[`183ead5bdacc701b3b626347a680a2f3cd3d4fbd`](https://github.com/sebh/UnrealEngineSkyAtmosphere/tree/183ead5bdacc701b3b626347a680a2f3cd3d4fbd)
(2022-09-11), including `Resources/RenderSkyCommon.hlsl` and
`Resources/RenderSkyRayMarching.hlsl`. This is a separate public research sample,
not the Unreal Engine 5.8 engine source or a 5.8 fork.

Its license is reproduced below for the algorithm reference and any adapted
portions. No private Unreal Engine source or third-party UE fork was imported.
