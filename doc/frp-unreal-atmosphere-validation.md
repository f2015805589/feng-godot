日期：2026-10-01。基准提交：`aa96f5cea74859bfd4f441b66e9e7be747a078dc`，分支 `feng-godot`。本记录区分本次通过的测试、原有失败和未验证范围，不能理解成全部引擎测试全绿。

参数与实现对应关系见 [UE 5.8 对照](frp-unreal-atmosphere.md)，全部插件审阅与剩余问题见 [架构复核](frp-addon-audit.md)。

## 构建

- Linux x86_64 编辑器构建通过：`platform=linuxbsd target=editor dev_build=no debug_symbols=no lto=none -j5`
- Linux x86_64 地形 GDExtension 构建通过，使用仓库自带 godot-cpp 与仅影响本地验证产物的精简绑定 profile。补上 Collision 对 PhysicsServer3D 的显式头文件依赖；未修改 vendored SDK
- GPU 使用 Vulkan 1.4.305、llvmpipe LLVM19.1.7。此软件 GPU 不等于用户的独立显卡/D3D12

直射光测试在不修改 Light3D 作者参数的前提下：不透明灰面从0.6118降至0.4471；前向从0.8039降至0.5961；透明/Volume路径约0.8039→0.5922。

60,000 lux、固定曝光的远墙采样中：Fog RGB变化约0.207，天空对雾的耦合开关亮度0.5439→0.2703；预曝光开/关 RGB 差为0。颜色发生显著变化却接近相同亮度时，回归检查使用 RGB差，避免把纯色相变化误判成无效果。采样仍必须由物理射线命中远墙，位于起雾距离之后且避开太阳方向瓣。

新模型的太阳、吸收、散射都进入真实求值；这仍不能证明 UE 5.8 像素相同。没有取得有权限的5.8引擎shader/CDO导出或匹配线性HDR截图，公开MIT样例只提供数学参考。

## 性能与成本

- 默认13个常规 Pass 仍开启；Debug Buffers关闭。TAA关闭的控制组为12个常规 Pass
- 48帧交替光照/软阴影/相机状态，预热10种变体后新增 draw pipeline 编译为0；本次 CPU中位1.267ms、P95约1.996ms。这保护已有 RunPass 缓存修复，不拿不同负载下的旧日志声称加速
- 1000次静态组件更新总耗时85–106ms；期间 settings、shader identity、光学/MS LUT、snapshot、material、ambient cache 的更新次数保持不变
- 光学列冷建约34–59ms，CPU数据96KiB；MS表冷建约0.47s，CPU数据3KiB。后者是初次/光学参数编辑成本，不能隐藏为正常帧开销。太阳色、强度、曝光、平移与MS倍率不重建MS表
- 太阳高度每跨新的2°缓存区间仍可能产生一次CPU天空积分；本机记录每次约6–15ms。每个 provider 保留自己的MS image，避免多世界共享缓存淘汰后重复冷建
- 固定320×240、每段120帧、不做像素回读时，软件GPU墙钟/帧：物理大气28.37ms、复测29.97ms，旧PhysicalSky25.50ms；非物理大气27.29ms、复测30.45ms，旧PhysicalSky27.48ms。Performance的process统计不是GPU计时器，两者不混为一谈

因此不能宣称用户原19ms帧已提升或完全不变。新增多次散射/空气透视有实际开销；目标显卡仍需同分辨率、同场景捕获。低耦合边界已让冷建和可见渲染成本可单独测量；后台/GPU LUT生成是后续优化方向，不以降低默认物理项覆盖来隐瞒成本。

## 全管线回归与架构修复

23个FRP回归场景在本次修改上执行：20项通过，3项保留原有失败；隔离工程导入通过。初次 Fog packet 夹具仍按240字节读取，已修为496字节：原240字节前缀、28个forward fog浮点值和新增64浮点Atmosphere尾部均有精确断言；80组与带真实大气快照的复测通过。

保留的三项失败与前次基准记录一致：

1. MSAA GBuffer 材质测试出现 `(0.0196,0.0196,0.0196)`
2. ViewState 的 LDR overlay 呈现为黑色
3. Post 的 after-tonemap overlay 没有呈现

其余包含Volume、视口世界切换、缓存、TAA/背景、管线来源、透明光照、Height Fog、Bloom、Eye Adaptation、曝光历史/生命周期、HDR太阳、Core调度及Forward+。旧失败控制依据见 [前次验证记录](frp-runpass-sun-validation.md)。

另外通过：Fog/GI租约与27项SH系数、完整PRT CPU套件、Tracy确定性所有权+真实连接压力、可选Blur/Bloom/FXAA图案GPU与旧资源迁移、地形C#源码/原生默认合同、通道打包失败注入、区域移动回滚、原生区域resize边界/文件保存/合并拆分、真实Terrain3D编辑器指针绑定、以及既有clipmap/allocator/signature独立合同。
