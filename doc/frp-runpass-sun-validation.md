# RunPass 卡顿与移动太阳黑斑修复验证

基准源码：`9d41bde2975ca2f634ad39dfff38741fec7f2bdf`。本次没有修改默认条目的开关：14 个条目中，13 个非调试条目仍默认开启。

## 已确认问题与边界

- 全屏 Lighting 只有一份 specialization 缓存。深度雾模式、方向软阴影或区域光可见性切换时，会释放旧管线并同步创建新管线。现在保留 8 个有界视图组合，仍按实际 framebuffer format / MSAA 样本数区分管线；全局质量设置变化会重新校验对应组合
- `run_pass()` 是 CPU 调用入口，不是独立 GPU 工作名称。新增受时间捕获开关控制的 `FRP <pass 名称>` 范围，并把全屏 Lighting 的真实同步缓存未命中计入现有 DRAW 编译计数
- 0.01° 太阳圆盘的两个 cosine smoothstep 端点在 FP32 中会同时舍入为 1。改用数学等价的弦长平方坐标，保持角尺寸与边缘曲线，没有引入新的任意亮度截断
- TAA 的 Reinhard 逆变换可把可表示的 65504 算成 65535，超出 RGBA16F 有限范围；现在在存储边界保护。历史 UV 越界时直接返回当前像素。最近深度对应的速度采样修复一像素偏移，并与深度采样采用相同的边缘钳制
- Color Grade 在中性参数下也可能把输入 Inf 经颜色混合变成 NaN。现在先修复非有限分量，精确读取原位纹理 texel，保护目标 FP16 存储范围，并跳过非精确的 `pow(x, 1)`

普通有限 HDR 颜色、雾的白色基础项与独立方向散射颜色保持原有协议。原有大气模型的存储上限与 LUT 精度/采样数不变。

## 编译与测试环境

Linux x86-64 editor：

```sh
scons platform=linuxbsd target=editor arch=x86_64 dev_build=no debug_symbols=no lto=none -j5
```

完整构建、最后增量构建以及旧缓存控制实验后的恢复构建均成功。Vulkan 执行设备为 Mesa llvmpipe / LLVM 19.1.7，属于软件实现；这里的绝对毫秒数不能当成用户显卡的帧率承诺。

## 缓存 A/B 实验

`misc/scripts/tests/frp_lighting_cache.gd` 使用两个视口、8 组视图状态、48 个测量帧，始终保留默认 13 个开启条目。控制版本只把缓存槽选择暂时设为 0，复现基准的单槽失效行为，同时保留相同插桩和其余代码。控制版本不在提交中。

| 指标 | 修复前控制 | 修复后第一次 | 修复后复测 |
|---|---:|---:|---:|
| 48 帧内新建 Lighting 管线 | 48 | 0 | 0 |
| 两视口 CPU 时间中位数 | 287.277 ms | 1.471 ms | 1.228 ms |
| 两视口 GPU 时间中位数 | 28.960 ms | 20.987 ms | 20.276 ms |
| 墙钟帧间隔中位数 | 326.044 ms | 27.593 ms | 24.050 ms |

CPU/GPU 项是视口渲染区间之和，墙钟项独立测量。这个实验确认重复同步创建管线的停顿来源；尚不能把用户报告的具体 19 ms 帧逐一归因。

## 数值与场景回归

- 生产天空 shader：8,192 条 GPU 射线全部有限；太阳边缘最大误差 0.000858。旧 cosine 表达式出现 1,732 个圆盘权重错误，计数不等同于最终画面 NaN 数量
- 生产 TAA 控制：复现 65535 的存储前溢出、一像素速度偏移和独立的边缘越界；完整修复均通过
- 生产后处理：高亮移动、1e24 历史曝光比例、无效历史恢复、当前 HDR 溢出测光、中性/非中性色彩分级均通过
- 真实 FRP 场景：物理光照单位和归一化单位各 12 组、36 次太阳区域捕获。覆盖 60k/10M 光强、0.01°/默认圆盘、相机与太阳同时运动、预曝光和 TAA 控制；曝光有限，未出现黑色太阳区域
- 每种单位模式的前 8 组保持 13 个默认条目开启。后 4 组仅在测试内明确关闭 TAA，作为额外对照；没有修改产品默认值
- 物理 60k-lux 白雾及天空耦合探针通过；预曝光开/关 RGB 最大差为 0.003922
- 天空组件/生命周期两种单位模式、15,600 个 LUT 样本、1,584 条积分射线、缓存回归、7 个曝光 CPU 测试及 Lighting specialization C++ 断言通过
- FRP 集成覆盖：TAA/背景、Volume、资源契约、世界切换、纹理/库布局、透明前向光照、Height Fog、Bloom、曝光生命周期、Core 调度和 Forward+ 均通过

透明光照独立测试修正了旧夹具的 TAA 开关：显式 FRP 管线应关闭其 TAA 条目，`Viewport.use_taa = false` 不控制该管线。它只影响该隔离测试。

## 仍存在的验证限制

完整回归不能宣称全绿。两项已知 LDR overlay 呈现测试仍失败。另一个 MSAA GBuffer 用例在旧单槽控制与修复版本上均得到相同失败；该早期场景没有执行本次修改的 TAA 或插件 shader，未纳入本次修复。按修正后的夹具设置，29 项主检查中 26 项通过、3 项保留上述失败。

本次未取得用户原始 19 ms 帧的 CPU/GPU 捕获，也未在用户的 D3D12/独立显卡上测量。
